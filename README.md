# 견적 정확도 체크

프리랜서를 위한 견적 정확도 분석 웹앱입니다. 정적 HTML/CSS/ES 모듈로 만들었고 빌드 과정과 외부 스크립트가 없습니다.

## 실행
```
python3 -m http.server 8000
```
브라우저에서 http://localhost:8000 을 엽니다. ES 모듈을 쓰기 때문에 `file://` 로 열면 동작하지 않을 수 있습니다.

## 주요 기능
- **대시보드**: 총 견적 금액, 총 실제 시간, 실질 시급, 적중률(±10%), 평균 편차율
- **고정 요약 바**: 화면을 내리면 상단에 프로젝트 수, 적중률, 평균 편차, 실질 시급이 고정됩니다.
- **요약 복사**: 핵심 지표와 제안을 텍스트로 만들어 클립보드에 복사합니다. 메신저나 메일에 바로 붙여넣을 수 있어요.
- **다음 견적 제안**: 완료 프로젝트가 3건 이상이면 가장 편차가 큰 카테고리 기준으로 가산율을 제안
- **카테고리별 / 고객별 평균 편차** 막대 그래프
- **추이 그래프**: 예상 vs 실제 시간 선 그래프, 프로젝트별 편차율 막대 그래프
- **월별 견적 금액과 목표선**: 월 목표 금액을 입력하면 막대 그래프에 목표선이 표시되고 달성 개월 수를 보여줍니다.
- **정확도 배지와 개선 제안**: ±10% 이내(좋음), ±25% 이내(주의), 그 밖(크게 벗어남), 진행 중. 프로젝트마다 다음 견적에 적용할 조언을 함께 표시합니다.
- **견적 템플릿**: 자주 쓰는 견적을 템플릿으로 저장하고, 새 프로젝트를 만들 때 불러와 채웁니다. 프로젝트 입력 창의 "템플릿으로 저장" 버튼으로도 저장할 수 있어요.
- **범위 변경(scope creep) 기록**: 프로젝트마다 변경 요청(내용, 날짜, 추가 시간, 추가 금액)을 기록합니다. 조정 견적(견적 + 추가 금액)과 견적 대비 비율을 보여주고, 범위 변경 요약 카드에서 전체 합계를 확인할 수 있습니다.
- **고객 태그**: 프로젝트마다 고객을 입력하고 고객별로 필터링과 정확도 요약 확인
- **검색, 필터, 정렬**: 이름/고객 검색, 카테고리·고객 필터, 최신순·편차순·금액순 정렬
- **수정 / 삭제**: 수정은 입력 창에서, 삭제는 확인 창을 거친 뒤 실행
- **CSV 내보내기 / 가져오기**: 엑셀에서 열 수 있는 UTF-8(BOM) CSV. 가져올 때 잘못된 줄은 건너뛰고 줄 번호와 함께 알려줍니다.
- **백업 파일 저장 / 복원**: 기록, 템플릿, 월 목표를 JSON 파일 하나로 묶어 저장하고 다시 불러옵니다. 이전 버전의 기록 배열 파일도 복원할 수 있어요. 복원하면 현재 데이터가 바뀌므로 확인 창을 거칩니다.
- **단위·반올림 도우미**: 작업 시간을 청구 단위(0.5/1/2/4시간)로 올림, 일 단위(8시간 기준) 환산, 가산율 적용, 시급 환산
- **테마**: 시스템 설정을 따르며 상단 버튼으로 라이트/다크 전환
- **예시 데이터**: 버튼 한 번으로 샘플 6건을 불러와 기능을 바로 확인

## CSV 형식
헤더 행이 필요합니다. 필수 열은 `name, category, quotedPrice, estimatedHours, date`이고 `client, actualHours`는 선택입니다.
- `category`: 디자인, 개발, 영상, 글쓰기, 기타 중 하나
- `date`: `YYYY-MM-DD`
- `actualHours`: 비워두면 진행 중인 프로젝트

## 데이터 저장
- 모든 데이터는 이 브라우저의 localStorage에만 저장됩니다. 다른 기기와는 공유되지 않으니 중요한 데이터는 백업 파일로 보관하세요.
- 키: `estimate-check:v1`(기록), `estimate-check:templates:v1`(템플릿), `estimate-check:settings:v1`(월 목표), `estimate-check:theme`(테마)
- 이전 버전에서 저장한 기록은 그대로 읽힙니다. 새로 추가된 필드(`client`, `changes`)는 없으면 빈 값으로 처리합니다.

## 테스트
```
npm test            # = node --test tests/*.test.js
node --test         # tests/ 자동 탐색
```
참고: Node 22에서는 `node --test tests/` (디렉터리 인자)가 모듈 경로로 해석되어 실패합니다.

## 구조
- `logic.js`: 순수 함수 (통계, 필터/정렬, 검증, 월별 합계, 범위 변경, 템플릿, 요약 텍스트, 백업 파싱, CSV, 단위 도우미). DOM에 접근하지 않습니다.
- `app.js`: DOM 렌더링과 이벤트 처리, localStorage 입출력
- `index.html`, `styles.css`: 마크업과 디자인 토큰(라이트/다크). 다크 모드에서도 배지와 차트 글자가 읽히도록 색상 토큰을 따로 정의했습니다.
- `tests/logic.test.js`: `logic.js` 단위 테스트
